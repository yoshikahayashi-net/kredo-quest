# クレドクエスト｜個人作業・受け渡し用

このリポジトリは、クレドクエストの個人側での確認・作業・ファイル受け渡しに使用します。

## リポジトリの役割

- 会社側の本番管理先：`hogetsu-kogyo/kredo-quest`
- このリポジトリ：個人側の作業・確認用
- 本番サイトの更新は、必ず会社側リポジトリの公開入口を確認してから行います。

## ファイルの扱い

- `index.html`：個人側の作業スナップショット。本番版として直接公開・上書きしないでください。
- `handoff/index.html`：受け渡し用のポイント修正候補。現在の受け渡しファイルはこの1つに集約しています。
- `admin.html`、`i18n.js`、`icons/` など：作業時に参照する関連ファイルです。

同じ内容のHTMLを別名で追加せず、更新する場合は対象ファイルを明示して差し替えてください。
本番へ反映する前に、アカウント別ポイント表示・クエスト加算・ポイント交換・履歴表示を実機で確認します。
