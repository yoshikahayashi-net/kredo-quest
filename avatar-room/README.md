# クレドクエスト｜アバター＆マイルーム独立試作

## 方針
このフォルダは既存のクエスト本体から独立した試作エリアです。既存の `index.html`、`avatar.html`、`myroom.html`、ポイント交換、Supabase設定は変更しません。本体との統合は試作の動作確認後に別工程で行います。

## 現在の範囲
- `index.html`: アバター設定ラボ（単体で動作する試作）
- 髪型・髪色・服装・アクセサリー・エフェクトの選択
- 選択中スタイルの一覧表示
- エフェクト表示の切り替え
- 保存／保存状態への復元
- 保存先はブラウザの `localStorage` のみ。本体アカウントやポイントには接続しない

## 開き方
`index.html` をブラウザで直接開きます。外部ライブラリ・APIキー・サーバーは不要です。試作データは同じブラウザ内に保存されます。

## 既知の制約
コンセプト画像は複数の画面を一枚にまとめた参照画像で、キャラクターの髪・服・アクセサリーが個別の透過素材として分離されていません。そのため、現段階ではキャラクター画像を参考表示として扱い、選択状態・保存機能とエフェクト表示を先に実装しています。キャラクターの見た目へ個々の選択を正しく反映する工程では、公式の部位別素材を用意して接続します。

## 次工程
1. このアバター画面の操作・保存を確認
2. マイルーム画面を別モジュールとして作成（テーマ、家具一覧、配置、削除、保存）
3. アバターとルームの状態保存を整理
4. 本体との接続設計（ユーザーID、所持アイテム、ポイント連携）を行い、統合テスト後に接続

## 安全条件
- 本体画面へのリンク追加・導線変更はまだ行わない
- 本番Supabaseへ試作データを書き込まない
- ポイント消費やアイテム解放の処理を試作側で実装したことにしない
