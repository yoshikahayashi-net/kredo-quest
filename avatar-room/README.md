# クレドクエスト｜アバター＆マイルーム独立試作

## 方針
このフォルダは既存のクエスト本体から独立した試作エリアです。既存の `index.html`、`avatar.html`、`myroom.html`、ポイント交換、Supabase設定は変更しません。本体との統合は試作の動作確認後に別工程で行います。

## 試作画面
- `index.html`: アバター設定ラボ
- `myroom.html`: マイルーム設定ラボ
- どちらも単独HTMLで、外部ライブラリ・APIキー・サーバーは不要
- 画面下部のリンクで、独立した2つの試作画面を行き来できます

## アバター設定ラボ
- 髪型・髪色・服装・アクセサリー・表情・エフェクトのカテゴリ切り替え
- 元のUI画像から切り出した透過WebPサムネイル20点を、選択肢に表示
- 選択状態の一覧表示、エフェクトのプレビュー、公式素材を受け入れるレイヤー合成の枠組み
- 保存、保存状態への復元、再読み込み後の設定保持
- 選択データは `localStorage` に保存

## マイルーム設定ラボ
- 5種類のテーマ切り替え（元のコンセプト画像から切り出したテーマ用サムネイルを表示）
- 家具と小物のカテゴリ切り替え、アイテム選択（10種類すべてに画像サムネイルを用意）
- アイテム追加、配置物の選択、ドラッグ移動、片付け
- レイアウトの保存、保存状態への復元、再読み込み後の設定保持
- 配置データは `localStorage` に保存

## 既知の制約
コンセプト画像は複数の画面を一枚にまとめた参照画像で、キャラクターの髪・顔・服装などが個別の透過素材として分離されていません。アバター画面にはレイヤー合成の枠組みを追加しましたが、公式の部位別素材が揃うまでは無効にし、参考画像をそのまま表示します。必要なファイル名・サイズ・レイヤー順は `assets/README.md` と `assets/avatar-parts.manifest.json` に記載しています。
部屋テーマと家具の選択カードには、元のコンセプト画像から切り出したサムネイルを追加しました。部屋全体の背景はまだCSSによる仮表示です。配置後の家具・小物10種類すべてに画像スプライトを接続しました。ソファ・ベッド・ライト・クッション・水槽は、動作検証用に作成した暫定SVG素材で、正式な製品アートではありません。製品用の部屋背景と残りの家具スプライトは次工程です。素材一覧は `assets/room-assets.manifest.json` に記録しています。

## 開き方
各HTMLファイルをブラウザで直接開きます。試作データは同じブラウザ内に保存されます。保存領域を消去したり別のブラウザを使ったりすると、試作データは共有されません。

## 次工程
1. 操作と保存のブラウザ実機テスト
2. キャラクターの部位別素材・背景・家具の素材整理
3. アバター設定とルーム設定のデータ形式を統一
4. 本体との接続設計（ユーザーID、所持アイテム、ポイント連携）
5. 統合テスト後に本体と接続

## 安全条件
- 本体画面への導線追加・既存画面の改変は行わない
- 本番Supabaseへ試作データを書き込まない
- ポイント消費やアイテム解放の処理を試作側で実装したことにしない
