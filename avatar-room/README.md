# クレドクエスト｜アバター＆マイルーム独立試作

## 方針
このフォルダは既存のクエスト本体から独立した試作エリアです。既存の `index.html`、`avatar.html`、`myroom.html`、ポイント交換、Supabase設定は変更しません。本体との統合は試作の動作確認後に別工程で行います。

## 試作画面
- `index.html`: アバター設定ラボ
- `myroom.html`: マイルーム設定ラボ
- どちらも単独HTMLで、外部ライブラリ・APIキー・サーバーは不要
- 画面下部のリンクで、独立した2つの試作画面を行き来できます

## アバター設定ラボ
- 顔型・髪色・服装・アクセサリー・エフェクトのカテゴリ切り替え
- 選択状態の一覧表示、エフェクトのプレビュー
- 保存、保存状態への復元、再読み込み後の設定保持
- 選択データは `localStorage` に保存

## マイルーム設定ラボ
- 5種類のテーマ切り替え
- 家具と小物のカテゴリ切り替え、アイテム選択
- アイテム追加、配置物の選択、ドラッグ移動、片付け
- レイアウトの保存、保存状態への復元、再読み込み後の設定保持
- 配置データは `localStorage` に保存

## 既知の制約
コンセプト画像は複数の画面を一枚にまとめた参照画像で、キャラクターの髪・服・アクセサリーが個別の透過素材として分離されていません。アバター画面ではキャラクターを参考表示として扱い、選択状態・保存機能・エフェクト表示を先に実装しています。実際の髪型・服装をキャラクター画像へ反映する工程では、公式の部位別素材を用意して接続します。
マイルームの背景と家具は、操作検証のための仮素材です。正式な背景・家具画像は素材を整理してから差し替えます。

## 開き方
各HTMLファイルをブラウザで直接開きます。試作データは同じブラウザ内に保存されます。保存領域を消去したり別のブラウザを使ったりすると、試作データは共有されません。

## 次工程
1. 操作と保存のブラウザ実機テスト
2. キャラクターの部位別素材・背景・家具の素材整理
3. アバター設定とルーム設定のデータ形式を統一
4. 本体との接続設計（ユーザーID、所持アイテム、ポイント連携）
5. 統合テスト後に本体と接続

## 安全条件
- 本体画面への導線追加・既存画面の改変は行わない
- 本番Supabaseへ試作データを書き込まない
- ポイント消費やアイテム解放の処理を試作側で実装したことにしない
