# アバター画像素材の受け入れ仕様

このフォルダは、本体と独立しているアバター試作の素材置き場です。現在あるコンセプト画像は画面全体のモックアップで、髪・顔・服装などの透明パーツに分離されていません。公式キャラクター画像を勝手に描き換えたり、画像を分割したように見せかけたりしないため、素材が揃うまで既存のキャラクター参照画像をそのまま表示します。

## 推奨ファイル構成

```
assets/
  avatar-parts.manifest.json
  avatar/
    body/base.png
    face/neutral.png
    hair/
      short/brown-back.png
      short/brown-front.png
      standard/brown-back.png
      standard/brown-front.png
      ...（髪型・髪色の組み合わせ）
    outfits/
      work.png
      casual.png
      outdoor.png
      formal.png
    accessories/
      cap.png
      glasses.png
      star.png
    effects/
      blue.png
      gold.png
      pink.png
```

## 画像の条件

- 推奨キャンバスは全パーツ共通の 512 × 768 px、PNG、透過背景です。
- 透明な余白を自動で削らず、すべてのパーツで人物の位置・大きさを同じにしてください。
- 人物の胴体ベース、服、顔、後ろ髪、前髪、アクセサリーは別々のレイヤーとして用意します。
- 髪型・髪色・服装・アクセサリーのIDは `avatar-parts.manifest.json` の定義と一致させます。
- 画像に背景や選択カード、チェックマーク、文字を含めないでください。
- アバターの顔・キャラクターのデザインを維持し、既存キャラクターの素材を元にした透過パーツを優先します。

## 現状

素材の準備状況は `avatar-parts.manifest.json` に記録しています。試作UIでは髪型・髪色・服装・アクセサリーを設定として選べますが、公式のレイヤー素材が未提供のため、キャラクター画像自体はまだ変化しません。エフェクトのみ、プレビュー背景の光として反映します。

素材が揃ったら、マニフェストの順番に従って合成し、すべての必須レイヤーを正常に読み込めた場合だけ参考画像から合成プレビューに切り替えます。不足素材や読み込みエラーがある場合は元の参考画像へ戻します。
